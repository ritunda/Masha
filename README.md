# Sokio

1. Supabase: create a project, run supabase.sql, turn off "Confirm email" (Auth > Providers > Email).
2. Open index.html, set SB_URL and SB_KEY (Project Settings > API: project URL and anon key). Never use the service_role key.
3. GitHub: new repo, upload these files to the root, Settings > Pages > Deploy from branch (main, root).
4. Open https://USER.github.io/REPO/ on Android in Chrome > menu > Install app.
5. APK: go to pwabuilder.com, enter the Pages URL, Package for Android, download and keep the signing key.
